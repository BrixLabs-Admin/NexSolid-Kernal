# Security policy

NexSolid Kernel is experimental software and is not yet production-ready.

## Reporting a vulnerability
Please **do not disclose an exploitable vulnerability in a public issue** before maintainers have had an opportunity to investigate.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Security** tab and its private reporting flow. Otherwise contact the repository owner privately through an established channel; a dedicated security contact is still to be configured.

Include the affected revision, steps to reproduce, potential impact, and any suggested fix. Do not include credentials, customer models, or confidential information.

## Supported versions
No stable releases or supported-version guarantees exist yet. Security reports for the current development branch are welcome.
