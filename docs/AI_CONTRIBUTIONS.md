# Using AI assistants when contributing to NexSolid

AI coding tools, including ChatGPT and locally hosted assistants, are welcome as optional development aids. No paid AI subscription is required to participate.

## Good uses
- Understanding OCCT types, algorithms, and compiler errors.
- Planning a small, reviewable C++ change.
- Creating initial test cases and explaining CMake/CTest output.
- Checking documentation for missing setup steps.

## Contributor responsibilities
1. Understand and review the final change yourself.
2. Build and test it against the documented toolchain.
3. Verify geometry results and numerical tolerances; AI output alone is not evidence of correctness.
4. Check that generated or suggested code does not copy incompatible third-party material.
5. Never paste secrets, private CAD models, personal data, or proprietary source into tools without permission.
6. In the pull request, disclose any material AI assistance when it helps reviewers understand what was generated or needs extra scrutiny.

AI tools cannot substitute for benchmarks, reproducible regression tests, human review, or the project's license obligations.
