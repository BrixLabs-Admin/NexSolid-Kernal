# Welcome to the NexSolid community

NexSolid is an **early-stage, open-source C++/OCCT CAD geometry project**. We want to work toward the reliability and capabilities expected of advanced CAD kernels, but we do not claim to have achieved that goal yet.

## New here?

1. **Curious?** Read the [project overview](../README.md) and [roadmap](../ROADMAP.md).
2. **Want to run it?** Follow the [getting-started guide](GETTING_STARTED.md).
3. **Want to help?** Browse [good first issues](https://github.com/BrixLabs-Admin/NexSolid-Kernal/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or read [your first contribution](FIRST_CONTRIBUTION.md).
4. **Found a problem?** Open a [reproducible issue](https://github.com/BrixLabs-Admin/NexSolid-Kernal/issues).
5. **Have an ambitious idea?** Start with an issue describing the problem, evidence, scope, and acceptance criteria.

## Do I need to join or request an invitation?

No. The repository is public. You can star, fork, report bugs, and open pull requests using a GitHub account. A maintainer invitation is only needed for direct write access.

## Is NexSolid already a Parasolid alternative?

Not today. NexSolid's goal is to help open-source CAD geometry reach world-class standards; the current repository is a starter project around OCCT. Work must be evaluated with reproducible tests and honest performance measurements.

## I'm new to C++. Can I help?

Yes. Reproducing a reported bug, improving documentation, making a small test case, or confirming build steps on a platform can be valuable. Avoid taking on core topology algorithms before you have a build and test setup.

## Can I use ChatGPT or other AI tools?

Yes—AI is optional. Review, run, and test everything you submit. Do not upload confidential models, secrets, or proprietary source. See [AI assistance guidelines](AI_CONTRIBUTIONS.md).

## Sharing NexSolid in other communities

When introducing NexSolid to FreeCAD, OCCT, CAD or C++ communities:
- Follow that community's self-promotion rules, and participate in discussion rather than posting repeated ads.
- Link to the repository: https://github.com/BrixLabs-Admin/NexSolid-Kernal
- Describe the **ambition** separately from what's **implemented today**.
- Invite specific technical feedback, bug reproductions, benchmarks, documentation improvements, or contributions.
- Be transparent that NexSolid depends on OCCT and is not yet a production replacement.

## Community standards

Be respectful and constructive. Review contributions based on evidence and maintainability, not seniority or whether code was written with AI assistance. Do not post secrets or private CAD models.
