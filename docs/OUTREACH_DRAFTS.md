## FreeCAD community

**Title:** Looking for early contributors: a small C++/OCCT kernel starter

Hi FreeCAD community,

I’m opening NexSolid Kernel, an early-stage C++ project using Open CASCADE Technology. It currently has a small CMake starter, a box example, and a smoke test. The immediate goal is to make the project buildable and welcoming before attempting larger geometry features.

I’d value feedback from people familiar with CAD kernels, OCCT, geometry testing, or contributor onboarding. First contributions could focus on improving the build instructions, adding tests, or discussing a small well-scoped geometry operation.
