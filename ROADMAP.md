# Roadmap

This roadmap describes direction, not promised release dates. Priorities may change as the project and contributor community develop.

## Phase 0 — Contributor foundation

- [x] Publish project overview and first-time setup.
- [x] Add CMake and OCCT starter example.
- [x] Add automated smoke test and GitHub Actions workflow.
- [ ] Select and publish the project license and contribution terms.
- [ ] Add a small set of well-scoped newcomer issues.

## Phase 1 — Stable kernel basics

- [ ] Agree on units, tolerances, error handling, and public API conventions.
- [ ] Add core shape inspection helpers with tests.
- [ ] Add deterministic examples for primitive creation and validity checks.
- [ ] Document supported compilers and OCCT versions.

## Phase 2 — Useful geometry operations

- [ ] Define the initial operation set based on contributor and user feedback.
- [ ] Add operations with input validation and regression tests.
- [ ] Add a simple sample that demonstrates composing operations.
- [ ] Document known numerical and topology limitations.

## Phase 3 — Data exchange and integration

- [ ] Decide which import/export formats are in scope.
- [ ] Evaluate a minimal integration path for CAD applications.
- [ ] Add compatibility and performance checks as real use cases emerge.

## How to shape the roadmap

Open an issue with the problem, a concrete example, and a way to verify a proposed solution. Larger items should be discussed before implementation.
